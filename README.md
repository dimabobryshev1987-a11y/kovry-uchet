# Учёт ковров

Простое приложение для iPhone: кому выдан ковёр, когда его поменять, когда забрать, телефон и адрес клиента.

## Как поставить на iPhone

1. Откройте ссылку в **Safari**: https://dimabobryshev1987-a11y.github.io/kovry-uchet/
2. Нажмите кнопку «Поделиться» (квадрат со стрелкой вверх).
3. Выберите «На экран Домой» и нажмите «Добавить».

На экране появится иконка «Ковры». Приложение работает и без интернета.

## Что умеет

- Выдать ковёр: имя или организация, телефон, адрес, описание ковра, дата выдачи, дата замены, дата вывоза, цена, заметки.
- Вкладка «Срочно»: те, у кого замена или вывоз просрочены, сегодня или в ближайшие 2 дня. Просроченные отмечены красным, ближайшие оранжевым.
- В карточке клиента кнопки «Позвонить» и «На карте».
- Отметки «Ковёр поменяли сегодня» и «Ковёр забрали».
- Поиск по имени, телефону и адресу.
- Сохранение копии данных в файл и загрузка из файла.

Данные хранятся только на телефоне. Копию стоит сохранять раз в неделю-две.
